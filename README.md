# Financial Dashboard

Frontend MVP for personal finance tracking built with React, TypeScript, Vite, Redux Toolkit, and Material UI.

## Documentation
- Product Vision: `docs/product-vision.md`
- User Flow: `docs/user-flow.md`
- Feature Backlog: `docs/feature-backlog.md`
- Feature Specs (implemented features): `docs/feature-specs/existing-features.md`

## Scripts
- `npm run dev` — start local development server
- `npm run build` — run TypeScript build + Vite production build
- `npm run lint` — run ESLint checks
- `npm run preview` — preview production build
