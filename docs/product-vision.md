# Product Vision

## Product name
**Financial Dashboard (Financy UI)**

## One-liner
A personal finance dashboard for individuals who want to track cashflow, understand spending categories, and quickly record new income/expense transactions in one place.

## Problem
People usually store finance information in scattered places (bank apps, notes, spreadsheets), which makes it hard to:
- Understand monthly vs yearly financial performance quickly.
- See where money is going by category.
- Add and review transactions without friction.

This hurts because delayed visibility leads to poor spending decisions and low confidence in budget control.

## Target user
**Primary user:** an individual user managing personal finances manually (no bank API sync yet).

**User goals:**
- See current balance, income, and expenses for a selected period.
- Understand expense distribution by category.
- Add new income/expense entries fast.
- Review latest transactions and open details when needed.

## Core value
The product provides a **single operational screen** where users can both **monitor** finances (cashflow + category analytics + recent activity) and **act** (add new transactions) with immediate feedback.

## Key features
- **Feature 1:** Period-based dashboard analytics (month/year switching for key financial widgets).
- **Feature 2:** Fast income/expense recording with validation and undo support.
- **Feature 3:** Recent transaction visibility with quick access to transaction details.

## Success metrics (1–2)
1. **Transaction capture completion rate:** percentage of users who successfully submit a new income/expense transaction from the add flow.
2. **Insight consumption rate:** percentage of sessions where users interact with period controls and review either cashflow cards or expense breakdown.
